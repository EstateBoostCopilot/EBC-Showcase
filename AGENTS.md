# EBC Showcase maintenance

This is a public documentation and media repository. The five application repositories remain private and separate.

1. Read `plan.md`, `docs/source-review.md`, and `docs/10-history-and-evidence.md` before revising claims.
2. Keep public writing in English. Use clear product explanations and concrete technical examples.
3. Do not copy application source, environment files, private logs, customer records, documents, datasets, prompts, access tokens, or local machine paths into this repository.
4. Treat counts as dated evidence. Preserve their definitions and distinguish team history from individual author-name matches.
5. Distinguish historical implementation, current source, planned improvements, and verified deployed behavior.
6. Keep diagrams readable on GitHub. Avoid unsupported HTML layout tricks or a backend dependency.
7. Document screenshot edits in `docs/media-notes.md`; never publish the unredacted customer-file screenshot.
8. Run `node scripts/validate-showcase.mjs` before publishing.
9. Changes here do not authorize changes to private product repositories or their production systems.
